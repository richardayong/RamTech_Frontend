This is the frontend for the RamTech Electricals Management System. It is built with HTML,CSS and JavaScript and connects to a decoupled Express/node.js backend hosted on render.

## Tech Stack
*   **HTML5 & CSS3** – Semantic layout and custom responsive styling.
*   **Vanilla JavaScript** – DOM manipulation, form validation, and Fetch API requests.
*   **Deployment:** [Vercel](https://ramtechelectricals.richardayong.me/)
